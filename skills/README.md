# Canon de los skills genéricos del marco

**La familia completa del método**, como fuente versionada con huella en `MD5SUM.txt`:

| Qué hace | Comando |
|---|---|
| retomar | `vuelamind-load` |
| cerrar | `vuelamind-commit` (el motor) |
| escalar | `vuelamind-upgrade` |
| censar | `vuelamind-skills` |
| identidad | `vuelamind-whoiam` |
| alma | `vuelamind-soul` |
| reintentar | `vuelamind-accidente` |
| comunicar | `vuelamind-mensajeria` |
| aportar | `vuelamind-learn` |
| sumar una máquina | `vuelamind-join` |
| catálogo de lo instalado | `vuelamind-help` |
| control remoto local | `vuelamind-rc` |

**Nacer no está en la tabla porque no es un comando**: se pega el master, y es él quien instala el ciclo. Antes esta lista lo nombraba como si fuera un skill más.

> [!warning] Esta lista es un inventario a mano, y por eso mintió
> Llegó a declarar **nueve** con **doce** en disco: se le habían caído `vuelamind-help`,
> `vuelamind-join`, `vuelamind-soul` y `vuelamind-rc`, y **nada falló** — ni el validador
> ni `MD5SUM.txt`, que comprueban las huellas de lo que está listado, no que la lista esté
> completa. El canon ya tenía escrita la regla, en `vuelamind-skills`: *«los inventarios de
> comandos mantenidos a mano mienten sin que nada falle»*. La tenía y no se la aplicó a sí
> mismo.
>
> **Quien añada un skill actualiza esta tabla en el mismo acto.** Y si tu dominio quiere la
> defensa de verdad, que su validador compare esta lista contra `ls skills/` — medir contra
> el disco es la única que funciona.

**La copia del nivel personal de cada máquina es la instancia viva, no la fuente.** En las máquinas con réplica automática las copias llegan solas y esta carpeta sirve para VERIFICAR; en las máquinas sin réplica (equipo administrado) esta carpeta es de donde se INSTALA y contra la que su copia declarada compara deriva.

**Dos reglas**: todo cambio a un skill genérico se publica aquí EN EL MISMO ACTO — un skill editado solo en el nivel personal es un canon mentiroso. Y **la familia se reconoce por su prefijo**: el nivel compartido de una máquina aloja exactamente esta familia, nada más — el reparto se lee en el nombre.
